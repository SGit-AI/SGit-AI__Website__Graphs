## How to use this pack

Open three fresh Claude Code sessions on this repository, one per book. In each, paste
the ENTRY PROMPT from the top of the matching entry file:

| Book | Entry file | Deliverable |
|---|---|---|
| A — the Universe volume | `03__entry-a-the-universe.md` | the atlas: the concept graph of Fractal Semantic Graphs, as a readable book |
| B — the book itself | `04__entry-b-the-book.md` | *Fractal Semantic Graphs: Meaning Through Connectivity* |
| C — the making-of | `05__entry-c-the-making-of.md` | *Creating a Book Using Fractal Semantic Graphs* |

Every entry prompt tells its session to read, in order: this README, `01__the-corpus.md`
(what to read and where it lives), `02__shared-conventions.md` (the rules all three books
share), and then its own entry file. The three sessions share the first three files
completely; only the entry file differs. That is the pack's design: the corpus and the
rules are said once, the editorial charters diverge.

## The three governing rules

1. **The title is locked; everything else is editorial freedom.** Books A and B carry
   *Fractal Semantic Graphs: Meaning Through Connectivity* (A as the companion volume to
   that title, B as the book itself). Book C is *Creating a Book Using Fractal Semantic
   Graphs*. Structure, voice, chapter count, figures — the writing agent's call, made
   confidently and recorded in the book's own front matter.

2. **Every claim is anchored or it is not made.** This estate's own discipline applies to
   its books: a position attributed to the corpus carries its source (a chapter, a brief,
   a page, a release note); a number is computed or quoted, never remembered; a
   screenshot is taken from the real page, never described from imagination. The corpus's
   own honesty lines survive verbatim — above all "not a graph database pitch".

3. **The reader is on a plane.** No live demo can be the argument. Each book must land as
   ONE self-contained PDF that reads start to finish offline, with the web version as its
   companion, not its crutch. Substantial but finishable: aim for a 60–120 page PDF, and
   say in the front matter what the reader will know at the end that they did not know at
   the start.

## What already exists that these books stand on

The estate is live at graphs.sgit.ai (v0.5.9 at the time of this pack): the frozen first
edition, the second edition's working surface (the universe reader, the core graph, the
identity ledger, the file explorers), the WCLM with its twelve operators in folders, the
38 briefs, the registers (methods, senses, analogies, meaning packs), the v0.4
retrospective, and a release history whose every row narrates what happened. Book A
compresses the ideas into a graph you can hold; book B argues them; book C tells how they
were built. Same corpus, three projections — which is itself the thesis.
