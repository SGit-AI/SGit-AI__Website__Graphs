# The Leanpub upload, held on purpose

Cover, metadata, sample and landing page are done and have been since v0.5.19. The
book builds to 92 pages. Nothing is missing.

**The hold is a decision, not a delay.** Uploading v0.2.0 would put a version on a
store that this estate already knows is superseded: part one is queued, the
vocabulary pass follows it, and both change what the book is for rather than what it
says in one chapter.

The window is free until the upload happens. That is the whole argument for using it.

## The plan

Upload after the restructure, not before. When it happens, the book's changelog entry
should name the **pack** and not just the release, because *"the workflow vocabulary
was written into the book"* answers *why did this version move* better than a number
does.
