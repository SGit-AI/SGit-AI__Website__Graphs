# Action: scope a structural change to a book

**Asked by** brief 40: *"we need to make a couple changes to the book structure."*

**Input** a stated dissatisfaction, usually a sentence from a memo.

**Method**
1. Name what is actually wrong, in one sentence, as a reader would experience it.
2. Locate it: which chapters, which order, which front or back matter.
3. Produce **two or three** options, each with what it costs — chapters moved, chapters
   rewritten, whether the book's version moves, whether the PDF must be rebuilt.
4. Recommend one, and say why the others lose.

**Output** `debriefs/NN__structure-<slug>.md`.

**Done test** the founder can choose without reading the book again. **Not a done test:**
having improved a sentence.
