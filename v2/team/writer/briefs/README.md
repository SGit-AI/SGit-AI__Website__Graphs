# Briefs for the writer

What this role was asked, newest highest, one file per brief: `vX.Y.Z__<slug>.md`, stamped with the site version at the time of writing, so it can be placed against the release history without being opened.

A brief names the question or the task, what the role may assume, and what "done" means.
It is written before the work, by whoever is asking — usually the founder through a memo,
or another role handing over.

Empty means this role has not been asked for anything yet, which is the honest state
until it has.
