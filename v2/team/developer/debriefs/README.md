# Debriefs from the developer

What this role did, and what it learnt, one file per piece of work: `vX.Y.Z__<slug>.md`, stamped with the site version at the time of writing, so it can be placed against the release history without being opened.

A debrief is not a status report. It records the answer, the evidence behind it, what the
role changed its mind about, and what it could not settle. A debrief that says only "done"
has failed.

Empty means this role has not run yet.
