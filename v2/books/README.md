# The bookshelf

Three books commissioned from this estate (brief 38), each written by its own Claude
Code session. Each folder below is one book's home: its README carries the full initial
prompt for the writing session, its `content/` holds the chapter markdown, and the
finished print PDF lands beside them.

| Folder | Book | Session branch |
|---|---|---|
| `fsg-universe/` | the Universe volume for *Fractal Semantic Graphs: Meaning Through Connectivity* | `claude/book-a-universe` |
| `fsg/` | *Fractal Semantic Graphs: Meaning Through Connectivity* | `claude/book-b-fsg` |
| `making-a-book/` | *Creating a Book Using Fractal Semantic Graphs* | `claude/book-c-making-of` |

To start a session: "hi, you are going to focus on writing this book:
`v2/books/<folder>/README.md`" — the README takes it from there.

The commissioning pack (shared corpus, conventions, and each book's editorial charter)
is at `v2/dev-packs/v0.5.10__the-book-writing-pack/`, rendered under `/v2/dev-pack/`.
The books do not wait for each other; book B in particular does not wait for book A.
