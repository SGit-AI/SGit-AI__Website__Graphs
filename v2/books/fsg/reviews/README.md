# Reviews of this book

The micro-format is the estate's one format for reviews and is specified once, at
[`v2/books/making-a-book/reviews/REVIEWS.md`](../../making-a-book/reviews/REVIEWS.md).
It is not repeated here, because a specification kept in two places is a specification
that will be true in one of them.

`gen_reviews.py` builds every book that has a `reviews/` folder. It was hard-coded to
the making-of book until v0.6.21, when the first reading of *this* book arrived and the
workflow turned out to have a book-shaped hole in it.
