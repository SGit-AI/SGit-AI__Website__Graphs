# NOTICE

## What this is

`aiuc-1` is an **unofficial, derivative, machine-readable representation** of the
public AIUC-1 standard, produced by the sgit.ai graph estate.

## What this is not

- It is **not** approved, certified, endorsed or reviewed by AIUC.
- It is **not** an official AIUC API, export or data feed.
- It is **not** a substitute for the standard. The official sources are canonical.
- It makes **no** compliance, certification, underwriting, insurance, legal, privacy
  or security claim about anybody, and cannot be used to make one.

## The official sources

| Source | What it is canonical for |
|---|---|
| <https://www.aiuc-1.com/> | the current public control text and its published presentation metadata |
| <https://www.aiuc-1.com/changelog> | the official release dates and release narrative |
| <https://github.com/aiunderwriting/AIUC-1-Changelog> | the official record of what changed between releases |

If anything here disagrees with those, **those are right and this is wrong**.

## How the sources were used

Public pages were retrieved with an explicit user agent identifying this build, at
most one request per second, honouring `robots.txt` (the site served no robots file
at capture time; the manifest records that observation). No authentication was used,
no private content was accessed, and no URL was guessed: every page fetched was
linked from a page already fetched.

Retrieved bytes are retained inside this vault as gzipped snapshots so a reader can
check a claim against what was actually received. They are evidence, not a mirror.
Extracted control wording is reproduced here for verification; **reuse rights for
the full control text have not been confirmed with AIUC**, and anyone republishing
this catalog publicly should confirm them first — `docs/source-policy.md` records
this as an open question, and the source manifest carries the same note on every
observation.

## Contact

sgit.ai project behind <https://graphs.sgit.ai>. Removal will be honoured.
