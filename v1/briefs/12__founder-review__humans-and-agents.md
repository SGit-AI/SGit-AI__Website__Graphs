# Founder review: a book for humans and agents

**Date:** 22 August 2026 · **Source:** voice memo, transcribed by Otter.ai, reproduced
verbatim below (per the house rule: the founder's voice is source material and is not
edited) · **Status:** Review **r002** on [the reviews register](../reviews/index.html),

[/reviews/r002.html](../reviews/r002.html). No content changes were made from this memo
directly: per the review workflow, the agent comments and proposes first.

**What it says, in one paragraph:** embrace what the book already half-is: a book for
humans **and** agents, stated in the identity and given a proper introduction. The
agent guidance should read like briefing the agent that is helping write it: name where
this material deviates from the standard usage already in an agent's memory (property
graphs, live graph databases versus the ephemeral serverless pattern here, acceptance,
the fractal concepts), and carry indexes for follow-up. The book itself is a graph and
should exist as one: each section with its facts, hypotheses, its own ontology and
defined terms; a machine-readable graph version, more expanded than print, with an
abstraction layer that can show just the facts, the key concepts, the narrative and the
objectives of a chapter. Words alone carry less meaning than words backed by evidence,
so the book needs a references and evidence layer (JSON files, cross-indexes, sources):
the 10,000-hours story is mentioned but not sourced, and "how do we know our version is
correct?" is exactly the question. The designed use is that a human hands the book to
an agent and asks "check the references, how much of this is correct?", and summaries
and infographics are made on demand: dogfood that on this book. Each chapter should get
a graph visualisation showing how deep the evidence goes, including assertions with no
evidence connected yet, shown honestly. Provide the machine surface as tools agents can
use. For the printed version, links must become footnotes, because hyperlinks die on
paper. And the missing pieces of the puzzle belong in a separate mapping, which is
where the graph of evidence starts to be visible.
